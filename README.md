# Alco-Work-Flow-Ai
Alur Kerja yang dibantu oleh AI — MVP scaffold untuk riset niche dan validasi masalah.

Run locally (Node.js required):

1. Install dependencies

```bash
npm install
```

2. Start server

```bash
npm start
```

Open http://localhost:3000 to see the frontend. The server provides mocked AI endpoints at `/api/niche` and `/api/validate` for development.

Next steps: connect real AI provider (Google AI Studio / OpenAI), add persistence, and integrate external webhooks.
